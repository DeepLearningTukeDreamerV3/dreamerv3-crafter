What we did and why

Goal. Train DreamerV3 on Crafter with the official config, check that it learns, and look inside its world model: how well does it predict the game, and how does one design choice, the imagination horizon, change what the agent learns.

Method. Upstream code at commit e3f0224, unchanged. Official crafter config, train_ratio 512. One NVIDIA H200 per run on the PERUN cluster (SLURM, Apptainer). Every run has an ID and a row in EXPERIMENTS.md before it starts.

Budget. 500k env steps and 3 seeds per setting, against the paper's 1M and 10. 1M would take ~18 h per run. Checkpoints are saved every 15 min, so "500k" means ~495k.

How DreamerV3 learns

  1. Act and record. The agent plays the real game; frames, actions and rewards go into a replay buffer.
  2. Learn the world model from replay batches (16 × 64 steps): compress each frame to a latent state, predict the next one from the action, decode frame, reward and "episode continues".
  3. Imagine. From real latent states, roll forward 15 imagined steps with no real game.
  4. Train actor and critic on imagination only. Real data trains only the world model.

With 5 imagined steps, a long chain like wood → table → pickaxe pays its reward beyond the rollout, so the actor sees it only through the critic. Quick rewards such as a zombie kill fit inside 5 steps. The means are too close to call one setting better; the two best agents use horizon 15, and horizon 5 is more consistent across seeds.

What it shows

Error grows with each imagined step because mistakes add up. At 213k the model beats "copy the last frame" from step 7 on; the player and terrain survive, trees and cows fade, and reward is predicted twice too high.

The 495k error is higher, but the test is not the same: that agent survives longer and reaches night, which Crafter draws dark with random noise. Reward flips from too high to too low. No window contains a death, so death prediction is untested.

During training, imagined reward per step was 1.6× the real one at 213k (0.035 vs 0.022). At ~495k they agree: 0.047 vs 0.045.
